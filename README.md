# M365 & Intune Policy Automation for Junior Sysadmins

> A GitHub repository demonstrating how to automate Intune policy assignments to dynamic Entra ID groups, integrated with an M365 SaaS engine.

## Overview

This PowerShell project was extracted from an article on [MSEndpoint.com](https://msendpoint.com) and is part of the professional automation portfolio.

### Quick Start

```powershell
# Clone the repository
git clone https://github.com/Msendpoint/m365-intune-policy-automation.git
cd m365-intune-policy-automation

# One-click install & run (checks prerequisites, installs modules, launches main script)
.\Install.ps1
```

## Tech Stack

PowerShell, Microsoft Graph, PHP

## Requirements

- PowerShell 7.0 or later
- Microsoft Graph CLI (if applicable)
- Appropriate administrative permissions
